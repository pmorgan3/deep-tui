# @deep-tui/plugin-ui-terminal

Provides Deep TUI's line-oriented terminal renderer, `run`, `help`, and
`theme` commands, plus interactive permission prompts for non-TUI use.

```json
{
  "use": "@deep-tui/plugin-ui-terminal",
  "config": { "color": true, "ask": true }
}
```

The full-screen interface is provided separately by
`@deep-tui/plugin-ui-tui`.
